Fix: a json_island(id, &v) helper that escapes < > & U+2028 U+2029 as \uXXXX inside <script type="application/json">. It is drafted in HANDOFF.md and has not been applied.

Stale DOM after in-place refresh

refreshMain() swaps <main> and never re-runs page scripts. Pages whose scripts capture elements once stop working after the first refresh:

  • Continents (8 s): the tree reverts to "loading…".
  • Overlord (3 s): the Messages lane goes blank.
  • Racks (5 s): hover filtering is lost.
  • Relay (4 s): the Start button goes dead and the meters paint detached rows.

The fix is data-keep, per-call lookups, or delegation.

Escaping in format!-built JS

The Rust esc() does not escape ' or \, yet inline handlers wrap it in single-quoted JS strings, for example connect('{id}',{i},'{name}'). A user-renamed port label can run script on click (Racks 3094, Relay 3300, plus nine more sites). The fix is to emit JS literals as esc(serde_json::to_string(v)). The {{ }} doubling disappears once the blocks become {PAGE_JS} arguments.

Exposed by the types

  • Overlord call.hops[0][0] throws on empty hops when the site is empty.
  • The device panel prints Cnull for an Option caster.
  • /api/device/ is never percent-decoded.
  • The editor shows "booked undefined" on a non-JSON reply.
  • Relay double-Start opens duplicate streams and tick loops, and an empty label matches any binding with an empty label.
  • Overlord's [data-proto="…"] selector is built from server data.

How to wire it in

Nothing in this section has been applied.

  1. Run node pages/build.mjs from TYPESCRIPT/. Then either commit dist/ or run the build from build.rs.
  2. Add const PAGE_<X>_JS: &str = include_str!("../../TYPESCRIPT/pages/dist/<x>.js"); for globe, continents, panels, panel-editor, overlord, racks and relay.
  3. Swap disc = DISCOVERY_JS to PAGE_GLOBE_JS or PAGE_CONTINENTS_JS, and delete the continents status <script>.
  4. Replace the format! IIFEs in panels, overlord and racks with <script>{PAGE_*_JS}</script>, and {EDITOR_JS} / {js} with the editor and relay bundles.
  5. Replace window.LIGHTS0=… and window.RELAY_*=… with json_island(…), placing each island before its bundle.
  6. Delete DISCOVERY_JS, EDITOR_JS and RELAY_JS. Smoke-test each page live.
  7. As a separate change, apply the stale-DOM and quote-injection fixes.

Risks and open questions

  • html.rs is being edited concurrently, so its line numbers will drift.
  • include_str! of a generated file breaks cargo build until the bundles have been built.
  • globals.d.ts guesses agent 01's signatures, and wire.ts is hand-transcribed and overlaps agent 04.
  • The latent bugs are preserved on purpose. Fixing them changes visible behaviour.
  • Open: should /relay stop refreshing in place?
  • Open: should bundles be inlined, or served as /assets/*.js?
  • Open: should agent 02 adopt the tc- island scheme?
