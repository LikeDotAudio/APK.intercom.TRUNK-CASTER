Findings

Bugs and latent issues in the Rust source

  1. HttpClient::rename can never succeed. client.rs:212 expects a Rename back, but the server returns Vec<RenameDispatch> (http.rs:484), so every call is a JSON error. Fixed in the TS port.
  2. The overnight quiet is lost. In DaySchedule::multiplier (types.rs:1333–1366), each newscast outside its window does m.max(1.0), which cancels the 0.3 overnight factor whenever any newscast exists, including on the default day. The port is faithful and a test pins it.
  3. Shapes change while WIRE_VERSION stays at 1. An old capture lacks bookings_per_hour and in_building_calls_per_hour, and the MQTT fields were added during this audit. TS readers need faderWithDefaults and the *_DEFAULTED lists.
  4. sites.json leaves out continent on all 50 sites sampled, so readers must call normalizeSites().
  5. slugify keeps ASCII only. “Brasília” becomes bras-lia, and bras-lia-01 is live in fader.json.
  6. Ward-Beck quoting gaps. A name with CR/LF splits the line on port 7879, and leading or trailing spaces are lost to trim. The TS port adds roundTrips(), and the client refuses CR/LF.
  7. Acks are counted loosely: wb.rs counts any non-CHECKIN line for a hosted frame as an ack, without matching it to a line that was sent.
  8. Sample::default() gives load_multiplier 0.0, but the serde default is 1.0.
  9. u64 fields become number, exact only up to 2^53 (Fader.seed). serde rejects a fractional number in an integer field, and NaN becomes null and then fails to deserialize.
  10. The request file is written non-atomically (client.rs:92), so the runtime can read a partial request.
  11. In mqtt.rs, len as u16 silently truncates strings over 64 KiB, and the reject payload is ambiguous if the reason contains |.
  12. vendor_badge checks substrings in order, so “Clear-Com Arts” gets the RTS badge. It affects colour only.

Mapping facts other agents can rely on

  • Every Option has skip_serializing_if, so it maps to field?: T and the runtime never sends null. The only exception is AllowedTrunk.trunks: (string|null)[].
  • No SDK enum carries data. All are string-literal unions with const value arrays, so no tag/content unions were needed.
  • flatten appears once, as an intersection (CrosspointEvent). The only rename is where_, which serializes as "where".
  • The labels use the Rust grapheme heuristic, not Intl.Segmenter, so TS cuts names exactly as Rust does. Trim follows Rust too: a BOM is kept and NEL is trimmed.
  • node --test … sdk/ fails with MODULE_NOT_FOUND on Node 24.11. Use the glob "sdk/**/*.test.ts".

How to wire it in

Nothing here has been applied.

  1. Every area imports shapes from ../sdk/index.ts. Node code imports clients from ../sdk/node.ts. Nobody re-declares a shape.
  2. Add {"path":"./sdk"} to the root references, and references: [{"path":"../sdk"}] to each consumer's tsconfig.
  3. Agent 06 can replace the frame-sim session loop with WardBeckClient, which handles the announce, adopt, echo-ack and check-in steps.
  4. Add ts-rs so the types are generated from Rust (Cargo.toml not modified):
[dependencies]
ts-rs = { version = "10", optional = true, features = ["serde-json-impl", "no-serde-warnings"] }
[features]
ts = ["dep:ts-rs"]

#[cfg_attr(feature = "ts", derive(ts_rs::TS), ts(export, export_to = "../../TYPESCRIPT/sdk/generated/"))]
pub struct Frame {
    #[serde(default, skip_serializing_if = "Option::is_none")]
    #[cfg_attr(feature = "ts", ts(optional))]   // `country?: string`, not `string | null`
    pub country: Option<String>, …
}
// TS_RS_LARGE_INT=number cargo test --features ts
// sdk/generated.check.ts: const _f: Eq<Gen.Frame, Frame> = true;  (tsc fails on drift)

Risks and open questions

  • The types are hand-written until ts-rs lands, and the crate is being edited right now. The schema checks and conformance tests are the only drift guard.
  • WardBeckClient has been tested against a mock hub, not the live caster. HttpClient uses fetch rather than raw TCP.
  • Open: should WIRE_VERSION be bumped for additive fields, or should the policy be written into plans/09-sdk.md?
  • Open: should the overnight-quiet bug be fixed? The fix changes load curves.
  • Open: should slugs transliterate accents? That changes frame ids on disk.
  • Open: should the Ward-Beck line escape CR/LF? That is a wire format change.
