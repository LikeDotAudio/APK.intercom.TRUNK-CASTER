Fix first, in Rust and Python, whatever happens to TypeScript

  • Security

    Path traversal through request ids. POST /api/request {"id":"../../x"} writes a file outside its folder, and /api/release can delete one. CORS is open and Docker binds 0.0.0.0:8080.

    Area 05 · runtime.rs:948, 1066 · users.rs:10 · found by reading, not exploited
  • Security

    Script injection in pages. JSON is spliced into <script> without escaping </ (GLOBE_DATA, LIGHTS0, RELAY_*), and esc() leaves ' inside single-quoted onclick handlers. Renamed ports and caller names can run script.

    Areas 01, 03, 09 · fix is a json_island() helper plus ' → &#39;
  • Data loss

    One typo wipes a config. A sites.json, globe.json or relay.json that fails to parse is overwritten with defaults, and nothing is logged.

    Area 10 · runtime.rs:134-149 · relay.rs:16-26
  • Stall

    Via-2 route search is O(F²·T) under the global lock. A JS copy took 8.6 s at 400 frames; the estimate for 710 is about 45 s per failing request, with HTTP, WS and Ward-Beck stalled. The TS port gets the same answers in 1.9 ms with three indexing changes Rust can copy.

    Area 08 · routing.rs:492
  • Logs

    3,989 glued JSONL records from two runtimes appending at once, and renames.jsonl at 206 MB, past the 100 MB cap.

    Area 10 · patches/util.rs.patch ready
  • Bugs

    The Rust SDK's HttpClient::rename always fails because it expects the wrong reply type. A call with no hops stops the map drawing until reload. Pages stop responding after an in-place refresh. Quadrant panes scroll to the top on every refresh. Reclaim releases only one red line. Overnight quiet never applies.

Suggested order of work

  1. Land the Rust fixes above. They don't depend on TypeScript.
  2. Make sdk/ the only home for wire types. Every other area holds local copies marked for dedup. Add ts-rs so the types are generated from Rust.
  3. Apply the build patches behind the ts-bundles feature. Plain cargo build stays unchanged.
  4. Swap the browser code page by page: web core, then the map engine, then the page scripts. Compare each against the inline version in a browser. None of the bundles has run in a browser yet.
  5. Run the Node simulator and panels side by side with the Python ones (not at the same time on the same ports), then retire the Python.
  6. Move page bodies to client rendering as the charts and Users proof show. Keep Rust rendering for first paint and the static snapshots.
