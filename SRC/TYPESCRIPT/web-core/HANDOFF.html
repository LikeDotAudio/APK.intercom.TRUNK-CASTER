Web core runtime

Convert

The shared page client (the JS const in RUST-RUNTIME/src/html.rs) ports cleanly to typed ES modules and bundles to one 35 KB IIFE that page() can include_str! in place of the const. Behaviour is preserved line for line (four small, documented deviations, all on crash-only paths). The typing turned up one user-visible bug, two storage hazards and one error path that shows “undefined”. The other inline scripts still call the core by bare name, so globals.ts republishes every original top-level name on window until those areas become modules.

Findings

  1. Bug: quadrant panes jump to the top on every refresh. refreshMain restores scrollTop only for :scope>.cols>.col. Quadrant mode is the default at ≥1200 px, and there .quads>.pane is rebuilt every REFRESH_MS, so each pane scrolls back to 0. That breaks the code's own “no scroll jump” rule. Fix (not applied): capture the panes by data-q and restore them after layoutCols().
  2. connect() alerts “undefined” on errors. /api/request answers 400 {"error"}, and api() never checks r.ok. The types made this visible (api<T>(): T | string, ApiError). Kept as-is and marked FIDELITY.
  3. The tc:main:* cache is write-only. The whole <main> is stored on every refresh and nothing reads it (repo grep). It grows until it hits the quota, and after that cacheSet('status') fails silently.
  4. A new build wipes the recent-tabs band. cacheFlush removes everything under tc:, including tc:topics, so the band empties after every deploy.
  5. Two full page reloads remain. One is on a WebSocket build mismatch (intentional, d4a8497). The other is toggleQuads(), which could re-layout in place.
  6. Storage hazards. The details.frame toggle calls setItem with no try. The open:*, cols:*, quads:* and layout.mode keys are never flushed.
  7. esc does not escape '. It is safe only in double-quoted attributes. RELAY_JS defines its own local esc without null handling.
  8. Per-frame layout cost. paintDay calls getComputedTextLength() on every clock label 60 times a second.
  9. Smaller items: a dead fmt local in applyStatus; a redundant ternary in the layoutQuads sash; auroraLoad never retries a failed fetch; /api/land repeats the inline TC_LAND.
  10. Telemetry contract. Only status carries build. globe-delta is a full snapshot every 2 s, and its inner shapes belong to GLOBE_JS (typed unknown here).

Deliberate deviations (crash paths only)

  • layoutQuads drag: checks that both panes exist before setPointerCapture, so a sash can no longer get stuck in drag. In practice this cannot happen.
  • auroraFrame: returns on a null 2D context.
  • parseTelemetry: drops a JSON null frame.
  • MathML children of <main> are not dealt. HTML and SVG children are, as in the original.

How to wire it in

Nothing here has been applied.

  1. Build from TYPESCRIPT/: node --experimental-strip-types web-core/build.ts (add --minify for 22 KB).
  2. Run the tests. If the drift test reports TODO, port the diff between source-snapshot.js.txt and the live const first.
  3. In RUST-RUNTIME/src/html.rs, replace the whole const JS: &str = r#" … "#; (L112–392) with: 
    const JS: &str = include_str!("../../TYPESCRIPT/web-core/dist/web-core.js");
    Leave page() exactly as it is. {JS} is a format! argument, so braces in the bundle are safe. The bundle must still run after const REFRESH_MS=…;const BUILD="…"; in a classic script, which is true today.
  4. Commit dist/web-core.js (recommended), with a CI step that rebuilds it and fails on a diff. Alternatively, add build.rs with cargo:rerun-if-changed on the bundle.
  5. Smoke-test every tab and check the console for ReferenceError. Then check Q / ▦, a sash drag plus double-click, ?pop=, the strip scrub, a WebSocket reconnect after a restart, and the build flush.
  6. As GLOBE_JS, DISCOVERY_JS, EDITOR_JS, RELAY_JS and the page scripts become modules, import from web-core/src and shrink REQUIRED to zero.

Risks and open questions

  • Moving target. html.rs is being edited concurrently, and the JS changed twice during this audit. Re-diff right before wiring.
  • Bare-name globals. TC and LIVE used to be global lexical consts and are now window properties. Bare reads behave the same, and no other script redeclares them (RELAY_JS's esc is function-scoped).
  • Bundle size. Unminified it is about 20% larger than the source (35.9 vs 29.3 KB); minified it is 22 KB.
  • Build-time dependency. Node and esbuild must be available, or dist/ must be committed.
