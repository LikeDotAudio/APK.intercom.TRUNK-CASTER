# Fiber Media Network

**Family:** Fiber Media Network
**Layer:** Any media, including intercom audio and control, with deterministic latency.

## What it is
A real-time network that carries video, audio, data and intercom together over redundant fiber between locations.

## How to connect to a device
- Single-mode fiber between network frames in a ring or mesh
- Intercom frames and panels plug into local ports on the media network frame
- Topology and signal routing configured in the network's management tool

## How to talk to a panel
- A panel at a remote site plugs into the media network and appears local to the matrix
- Configured as a normal port

## What it carries
Everything, over fiber.

## Trunking notes
The long-distance, high-capacity trunk for a single-brand estate spanning buildings or venues.
